# Hold My Steering v1.0.0

Use your Android phone as a steering controller for PC games.

## Installation

### Windows Receiver

1. Install ViGEmBus:
   `ViGEmBus_1.22.0_x64_x86_arm64.exe`

2. Install:
   `HoldMySteeringReceiverSetup.exe`

### Android App

Install:

`app-release.apk`

## How to Connect

1. Open Hold My Steering Receiver on Windows.
2. Open the Android app.
3. Enter the PC IP address.
4. Press Connect.
5. Open x360ce for syncing with xbox controller
Make sure both devices are connected to the same WiFi network.
